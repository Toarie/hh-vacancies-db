# Проект: База данных вакансий с hh.ru

## Описание
Проект позволяет получать данные о компаниях и их вакансиях с сайта hh.ru, сохранять их в базу данных PostgreSQL и работать с этими данными.

## Основные функции
- Получение данных о компаниях и вакансиях через API hh.ru.
- Создание и заполнение таблиц в базе данных PostgreSQL.
- Работа с данными через класс `DBManager`.
